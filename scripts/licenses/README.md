# Avisos complementares

`vue-devtools-api-6.6.4.LICENSE.txt` preserva o texto MIT da [tag v6.6.4 do repositório vuejs/vue-devtools](https://raw.githubusercontent.com/vuejs/vue-devtools/v6.6.4/LICENSE), consultado em 15/11/2026. O pacote npm `@vue/devtools-api@6.6.4` declara MIT e essa origem, mas publica somente `lib` e `package.json`.

O gerador exige essa versão exata antes de usar o complemento; uma atualização que mude a licença precisa ser revisada. O arquivo final inclui a árvore de produção mesmo quando o bundler remove um pacote.
